# Application form (email format)

The CV is the application. If you prefer a bit of structure, copy this into
your message to mirellepartners@gmail.com:

```
Role applied for (or "open application"):
Full name:
Email:
CV attached: yes / link
Anything we should know (optional):
```

That's genuinely all we need to start. Phone, location, notice period,
salary expectations, and work authorization come later, in the intro call,
when there's a real conversation to have them in. We ask for personal
details when they're needed, not because a form has fields.

Everything you send is handled under our candidate privacy notice
([../policies/privacy-notice.md](../policies/privacy-notice.md)).
